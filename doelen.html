Leerdoelen

Drie concrete doelen die ik dit semester wil bereiken en waarop ik mezelf toets.

  1. 01

    Meer leren over interactieve frontend development met JavaScript

    Ik gebruik JavaScript nu vooral voor basisfunctionaliteiten, maar merk dat ik nog moeite heb met complexere interacties binnen websites. Daardoor zoek ik vaak lang naar oplossingen of gebruik ik code zonder volledig te begrijpen hoe het werkt.

    Dit semester wil ik vaker zelf interactieve componenten bouwen, zoals filters, menu’s en dynamische content. Het doel is dat ik aan het einde van het semester zelfstandiger JavaScript kan gebruiken en beter begrijp hoe mijn code werkt.

  2. 02

    Sterkere en aantrekkelijkere interfaces ontwerpen en bouwen

    Mijn websites werken meestal technisch goed, maar ik wil meer aandacht besteden aan hoe een interface eruitziet en aanvoelt. Ik merk dat ik nog zoek naar een sterkere visuele stijl en meer vertrouwen wil krijgen in frontend design.

    Dit semester wil ik experimenteren met layout, typografie, kleurgebruik, animaties en spacing. Het doel is dat ik aan het einde van het semester een frontend project kan maken dat zowel functioneel als visueel sterk is.

  3. 03

    Zelfstandiger worden binnen mijn developmentproces

    Tijdens opdrachten merk ik dat ik snel vastloop of direct hulp zoek wanneer iets niet meteen lukt. Daardoor twijfel ik soms aan mijn eigen oplossingen en besteed ik minder tijd aan zelf onderzoeken en experimenteren.

    Dit semester wil ik bewuster eerst zelf testen en problemen oplossen voordat ik hulp vraag. Het doel is dat ik aan het einde van het semester met meer zelfvertrouwen zelfstandig aan frontend opdrachten kan werken.
